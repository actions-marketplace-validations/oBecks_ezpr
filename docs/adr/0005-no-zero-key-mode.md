# No zero-key mode; one free Gemini key is the default

The brief promised "works with zero API keys" via GitHub Models and `GITHUB_TOKEN`. GitHub Models was retired on 2026-07-30, and no reliable free keyless LLM replaces it. We drop the zero-key promise: the setup is one free Gemini (AI Studio) key, and a run with no key posts a Setup comment explaining how to add one. Unofficial anonymous endpoints were rejected: unreliable, and they would receive user code with no account or terms.
